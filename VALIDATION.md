# Validation of the redesigned desktop (0.3)

- Nineteen Rust tests passed. New checks cover Bulgarian Markdown extraction, code-block exclusion, synchronized task checkboxes, import/watch deduplication, stable action identity and independent global completion, and persisted Bulgarian/model settings passed to Whisper without ffmpeg for a native WAV. The speech configuration test uses a deterministic recognizer fixture and does not measure Bulgarian recognition accuracy.
- Native GUI tested in a Linux virtual display: visually inspected workspace, Bulgarian conversation notes, next-steps panel, global actions, and settings. Used real native controls to add a session action to Global actions, complete the session copy independently, and switch to Light; verified persisted state and synchronized Markdown. Cyrillic, headings, lists, and emphasis rendered correctly.
- Real Whisper through the redesigned native GUI: selected English for the public whisper.cpp JFK sample, triggered transcription, and verified the expected country/ask passage in the persisted transcript. Native PCM WAV was passed directly to Whisper. This English sample does not validate Bulgarian recognition quality.
- Linux and Windows Clippy with warnings denied passed. Windows x64 native release cross-build passed using Rust's GNU LLVM target. The executable uses the Windows GUI subsystem.
- Pinned whisper.cpp v1.8.7 cross-built as a static Windows executable using verified LLVM-MinGW. Its inspected imports are Windows/UCRT system libraries; no MSVC runtime or Whisper DLL installation is required. The ZIP includes this engine, the verified tiny model, app runtime DLL, Inter font/license, and dependency notices. No PowerShell/setup scripts are distributed.
- Live subscription agent generation remains unverified: the cloud's existing Codex token previously returned HTTP 401. Both CLI contracts are checked with mock processes; a detected CLI is not evidence of working subscription access. No credentials were copied or changed.
- Physical Windows capture/playback, device pause/resume, floating-widget appearance and dragging, and both Windows executables have not been run on Windows. Cross-build and Linux checks do not prove that behavior. Bulgarian recognition accuracy still depends on the chosen model and audio quality.
